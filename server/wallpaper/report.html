留存与时长口径

新增按所选流量中首次观测日期分组；D1/D7/D30 为准确第 N 天活跃比例，并非期间任意回访。前台每分钟累计一次时长，离开页面补计剩余时间。强制结束或断网可能少计；这是桌面或手机应用的前台时间，不是电视总观看时长。

采集覆盖与保存期限

本版 MAC 辅助统计默认关闭，需阅读新说明并重新开启。服务器不保存或展示原始 MAC；系统可能限制读取，网络接口变化也可能影响去重。模拟器自动标记测试，实体测试机可手动标记；默认报表排除测试。匿名路径和问题明细保留 30 天，按安装分组的日活明细保留 400 天。旧版无 ID 的数据无法补填留存；没有数据时不显示伪造的 0 安装。

如何理解旧版数据

会话不等于设备

电视桌面结束一次前台使用后上报会话与时长。同一台电视可以产生多次会话；手机启动、连接及清理也均可重复计数。旧版接口无法统计独立安装设备或新增安装。

没有上报不等于没有使用

电视端统计默认关闭，网络失败的会话不补传。手机事件也受统计授权与网络影响。旧版测试事件无法区分；这部分仅供观察使用趋势，不是完整安装量。
