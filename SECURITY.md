# Security

Report vulnerabilities and sensitive issues privately to [support@gentv.me](mailto:support@gentv.me). Do not publish credentials, TV addresses, account details, signing keys or device identifiers in issues.

Include the affected component and version, reproduction steps and expected impact. The project does not promise a fixed response time. Credit should follow the reporter's preference.

ADB access, package protection, backup and restore, desktop components, updates, file transfer and the server are in scope. GenTV uses the permissions and authorisation offered by the device; close debugging and revoke ADB authorisations after maintenance. No report grants permission to modify another person's TV.
