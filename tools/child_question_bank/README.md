# GenTV 离线题包 1.0.1

此目录是题包的可复现源文件和生成工具；运行时资产位于 `launcher/app/src/main/assets/child-questions/`。

```sh
python3 tools/child_question_bank/generate.py
python3 -m unittest discover -s tools -p 'test_child_question_bank.py'
```

- 60 个计算模板，每级 10 个。每模板最多生成 200 个不同题面；低年级参数空间有限，不凑数重复。所有计算题均使用精确分数计算，经独立测试逐题代入四个选项验证唯一答案。
- 300 个原创、AI 辅助编写的英语词条，每级 50 个。每词条生成词义到单词、单词到词义、英文释义/语境选词、拼写辨认四种练习，共 1,200 道，每级 200 道。这个数量不代表 1,200 个不同词汇或语境。
- 英语题全部为待教学审校草稿。中英文题面/选项随界面语言切换；其他界面语言退回英文。中文词义练习不是通用于所有国家的题包。一、二级共 16 道词义到单词题已替换为看图选词草稿，其他题型仍以文字为主，不宣称完整实现看图启蒙或符合任一国家的教学进度。
- 部分拼写干扰项由字符变换生成，当前只排除了本地词表中的真实词；必须由审校者排除其他真实词、歧义和超纲内容，不能把自动校验当作英语教学审校。

## 运行时接入

计算题包用于正式出题；新增英语草稿仅供家长预览。每级不足三道已审校英语题时，正式轮次继续使用原有 18 道内置英语题（每级 3 道），也通过洗牌队列避免在一轮题库遍历结束前重复。已有六张图片和旧题仍保留作兼容回退。

每个年级/学科/题包哈希各自保存洗牌种子和游标。题目快照、稳定 ID、版本、队列游标在同一次 SharedPreferences 提交中写入。预览不消耗正式题库队列，不改变错误次数和计时。更新后保留已展示的旧题快照；新题使用新哈希的队列。文件缺失、校验失败或结构无效时使用旧生成器回退，避免因为题包问题无法答题。

题包先内置随 APK 发布；未实现联网下载、热更新、远程审校、完整多语言题包和自适应升降级。数学模板生成后的题目以离线资产运行，电视无需 Python。

## 教学审校流程

逐题检查释义、译义、唯一正确答案、干扰选项、年级、拼写和文化适用性。改题先改源数据/生成逻辑，再生成。每个批准题目在 `reviews.json` 中以稳定题目 ID 为键，记录 `reviewer`、`reviewed_at`、`sha256`。哈希是审批前完整 JSON 对象（含 draft 状态）按 UTF-8、键排序、紧凑分隔符序列化后的 SHA-256。生成器只接受匹配内容的审批；内容变化后旧审批失效并报错。审批记录不得伪造或用 AI 自检冒充教师审校。

审批后的题目才进入正式英语出题池。首批未达到覆盖与题量要求前，不应将新版英语库宣传为已正式交付。数学自动验证也不代表年级教学审校完成。

## 难度覆盖

| 级别 | 计算模板覆盖 | 英语词汇方向 |
|---|---|---|
| 1 | 10/20 以内加减、缺数、三项加减 | 动物、食物、文具、日常物品 |
| 2 | 百以内加减、表内乘除、简单两步运算 | 身体、家庭、地点、食物、颜色 |
| 3 | 三位数加减、一位数乘除、括号和缺数 | 时间、季节、天气、动作、感受 |
| 4 | 多位数乘除、四则组合、小数加减 | 公共场所、生活物品、地理、形容词 |
| 5 | 小数乘除、分数加减、缺数和组合 | 动作辨析、品格、常见抽象形容词 |
| 6 | 分数乘除、百分数、增减百分比 | 抽象概念、多义词指定含义和短语 |

这是产品难度草案。词汇六级尚不等同于六年级语境阅读题库；五、六级已包含 100 道有独立例句的语境填空草稿；其余级别后续仍需增加语境覆盖，并继续扩充一、二级配图及词条级知识标签。后续扩充应增加有效知识覆盖，避免只靠改写题干增加题量。

生成时同时输出 `output/child-question-bank/english-review.csv`，可直接在表格软件中按年级审阅题面、四个选项、正确答案和内容指纹。它是审校交付件，不是审批结果。

## 审批门槛自动检查

`reviewer` 必须是非空字符串，`reviewed_at` 必须是有效的 `YYYY-MM-DD` 日期；空审批对象、未知 ID、非英语审批和内容指纹不匹配均会终止生成。全部审批校验通过后才修改题目状态，校验失败不会改写现有资产。工具只验证记录结构与内容绑定，不能验证审校人的身份，也不能代替真实教学审校。

`manifest.json` 的 `english_release_status` 按六级记录总题量、已审题量、草稿题量、已审题型分布及正式出题来源。每级至少三道批准题时来源为 `pack`，否则为 `legacy-18`，与 Android 当前运行门槛一致。这只是运行门槛，不代表教学覆盖达标；应同时检查题型分布与知识覆盖。自动测试使用内存中的虚构审批夹具，不写入 `reviews.json`。

## 低阅读负担与家长预览（1.0.1）

一年级 10 道、二年级 6 道新题使用 `picture_word`，复用 5 张已有矢量图并增加 11 张矢量图，不增加总题量。题面保存 `picture:<lemma>`，由 Android 渲染图片；四个选项仍为短英文词。英文与中文均使用同一图形，避免把中文翻译当作跨语言看图题。颜色题仅以色块呈现，仍需评估色觉差异；没有配音，不能宣称已满足所有非阅读儿童的需要。图片不在无障碍描述中泄露答案。

低年级英语预览从配图题开始，随后交替穿插文字题以展示阅读负担差异，正式洗牌队列不受影响。家长预览常驻显示分级范围、国内小学年级参考与待审校提醒，设置页随年级切换刷新范围。长题卡支持遥控焦点触发滚动；一次确认即提交；家长预览随后显示可停留阅读的答案与释义，选择“下一题”后继续，不用 Toast 覆盖新题选项。新配图题依旧是待教学审校草稿，需逐题核对图意、唯一答案与干扰项；审校 CSV 的 `picture:` 标记对应 `launcher/app/src/main/res/drawable/child_picture_<lemma>.xml`，应在实际预览中审图。
