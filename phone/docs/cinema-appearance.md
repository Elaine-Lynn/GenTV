# GenTV appearance

GenTV TV provides its own dark television interface, remote focus treatment, application tiles, input tiles and optional wallpaper rendering. GenTV Remote can edit the options exposed by the current desktop schema.

Appearance drafts do not change system package state or remove applications. Existing user-selected pictures and recoverable configuration remain authoritative. A preview or emulator image is not proof that an input or device-specific service works on every television.

See [desktop protocol](../../docs/desktop-protocol.md), [phone setup](../README.md) and [third-party notices](../../THIRD_PARTY_NOTICES.md).
