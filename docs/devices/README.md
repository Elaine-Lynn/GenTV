# GenTV device references

252 TV, box and projector models from the community, grouped by brand. 共 252 款电视、盒子和投影仪的社区参考，按品牌分组。

Each entry is a cleanup reference used by the GenTV phone app: the model and firmware it was checked on, which packages were disabled, which were kept on purpose and why, and notes on ADB, Home and inputs. It is **not** a compatibility certification, and the commands inside are historical notes, not GenTV instructions. Check your own model and firmware before you change anything.

每份清单记录了机型和固件、停用了哪些应用、哪些刻意保留以及原因，还有 ADB、桌面和信号源方面的笔记。它们**不是**兼容认证，里面的命令是历史记录，不是 GenTV 的操作步骤。动手前请先核对自己的型号和固件。

How to turn on ADB: [by brand](adb-by-brand.md) · [分品牌打开 ADB](adb-by-brand.zh-CN.md)

Found a model that isn't listed, or a note that is wrong? See [CONTRIBUTING.md](../../CONTRIBUTING.md); say which model and firmware you checked.
