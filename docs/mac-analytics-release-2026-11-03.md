# MAC 辅助统计客户端发布 · 2026-11-03

电视 \`com.gentv.tv\`：3.7.7 / code29；手机 \`com.gentv.mobile\`：3.7.4 / code20。官网中英文首页、release.json、下载文件、隐私说明及两端升级接口同步更新。更新保持非强制，旧 debug 签名迁移通道仍为 3.6.1 / code21。

## 行为与限制

两端改用 schema 3，在用户阅读新版说明并主动开启统计后，尝试通过系统公开接口读取本机 wlan0、eth0 的有效出厂 MAC。为空、不可读取、格式错误、全零、组播或本地管理/随机 MAC 时回退安装 ID，不使用 root、ADB、shell 或路由器地址绕过限制。服务器不保存或展示原始 MAC，只保存按应用隔离的 HMAC 和安装 ID 哈希映射。

同一有效 MAC 的重装实例在报表中归一，时长、会话与事件继续累加；后续首次读取到 MAC 可关联该安装的保留历史。历史从未上报 MAC 的其他重装实例不能追溯关联。Android 限制及网络接口变化仍影响覆盖率，指标不保证等于物理设备台数。两端升级后本版统计默认关闭，不继承旧协议的开启状态；关闭会清空待发事件并重置安装 ID，但不会撤回历史 MAC 关联。正式流量、测试流量及两端应用继续独立聚合。
