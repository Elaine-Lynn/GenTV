# 个性化中的在线壁纸

个性化页面包含内置、在线和用户自定义三行 Leanback 横向列表。在线行读取构建配置 `API_BASE_URL` 下的 `wallpaper`，对应现有服务端 `GET /tv/wallpaper`。不配置 API 时显示不可用入口；请求失败可点击重试。接口未部署、DNS 或 HTTPS 失败时不会影响内置和自定义壁纸选择。

当前服务端的 `{ "wallpapers": [{ "id": "…", "url": "https://…/tv/wallpapers/example.jpg?v=…" }] }` 格式可直接使用。当前范围为静态图片；最多 100 个不重复图片 URL，每张不超过 8 MiB、840 万像素。来源必须与配置的 API 同源，且位于 `wallpapers/` 下的单个文件路径，拒绝路径穿越、凭据、片段和跨站图片地址，不跟随重定向。

列表可选读取每项 `title` 和 `thumbnailUrl`；没有标题时显示“在线壁纸 N”，没有缩略图时下载并采样原图。现有服务端尚未生成专用缩略图。图片下载和解码在线程中进行，不阻塞遥控器焦点。焦点预览延迟返回时不会替换用户当前查看的其他图片。

浏览页使用独立的 64 MiB 临时图片缓存，并保存最后成功的列表，离线时可显示已缓存内容。用户点击卡片后，将原图导入应用私有的自定义壁纸目录，再应用为当前壁纸；此后无需联网显示。相同版本 URL 重复选择复用已导入文件；服务端图片变化应继续使用现有内容摘要查询参数，避免命中旧缓存。缓存可被系统回收，用户主动保存的自定义文件与临时缓存分开。

自动轮播原有的流量策略不变；这里的下载由用户打开选择页和浏览卡片触发。已导入的在线图片也会出现在“用户自定义”行。

自动城市定位在未选城市时最多每 24 小时尝试三次，失败尝试间隔五分钟。工具箱进入二级页面时保留 Activity 和焦点，返回后继续显示；返回键和点击遮罩仍可关闭。选择移动应用操作时需回到首页执行，因此离开工具箱。

验收包括：在线接口成功/空列表/断网、切换在线与本地预览、三行间上下导航、下载后返回首页与离线显示，以及工具箱进入个性化再返回时保持展开与焦点。当前网络对 API 域名的解析问题会阻碍真实在线列表验收，需要网络恢复后复测。
