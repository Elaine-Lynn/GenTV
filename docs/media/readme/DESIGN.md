# Quiet Signal

深色空间是安静的底层，真实界面是画面的中心。所有介绍图以克制的留白和准确的比例建立秩序，让产品本身承担表达，而非依赖外加装饰。每一条边缘与每一处间距都经过细致校准。

色彩从界面中提取：近黑背景、柔白文字和浅蓝标记。山湖、沙漠、森林与夜空保留各自的色彩关系，展示生活空间可以具有不同气氛。精细的配色控制让背景退后，让功能显现。

标题使用 Outfit，辅助文字使用 Instrument Sans。字重与字号只建立必要的层级，不覆盖截图里的操作信息。排版追求专业而细腻的完成度，保持清楚的边界与稳定的节奏。

截图作为证据保留完整内容，介绍图只做等比缩放和外部排版。模拟器截图与测试渲染明确标注，设备和数据保持演示性质。精心制作的视觉表达应同时具有可信度与可读性。
