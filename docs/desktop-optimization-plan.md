# GenTV development plan

The current products are GenTV TV (`com.gentv.tv`) and GenTV Remote (`com.gentv.mobile`). The public source and support destination is [Elaine-Lynn/GenTV](https://github.com/Elaine-Lynn/GenTV).

Priorities:

1. Keep focus, navigation, installed-app identity and current user configuration stable.
2. Maintain a single source-built GenTV TV delivery in the phone.
3. Verify desktop read/save/undo, local images, folders and input labels against the documented schema.
4. Keep release identity, signatures, updates and optional analytics consistent across platforms.
5. Test real-TV Home, standby, reboot, HDMI, remote buttons and recovery before claiming device acceptance.

This plan is not a device certification or a record of an online release. See [implementation](implementation.md), [protocol](desktop-protocol.md), [release requirements](release.md) and [third-party notices](../THIRD_PARTY_NOTICES.md).
